## 这六档配置差在哪

1核1G 和 2核2G 的差距主要在内存。1GB 跑 WordPress 是底线，插件一多、后台一开，PHP 进程就容易顶到天花板；2GB 之后后台不卡，缓存插件也能跑开。

2核4G 到 4核8G 多出来的是并发余量。数据库读写频繁、装多个站点、同一台机器上再跑个定时任务或者 Docker，4GB 内存比 4 个核更管用。

带宽那一栏要分开看。10M 到 35M 是给网页和 API 用的，够跑一个日访几百到几千 PV 的站；100M 到 1000Mbps 的大带宽是给下载、视频中转、AI 接口调用这类场景准备的，网页本身用不上。洛杉矶大带宽这条线每月 1TB 流量包，跑完不额外扣钱，直接限速，想要恢复速度就买流量包。

## 下单前必须看清的六条限制

**退款只退到余额，每人 3 次。** 新购产品支持 7 天无理由退款，在控制面板自助操作，每位用户限 3 次。领过积分、参加过 1 元试用、或者已经续费过的订单不能退；日付、流量包、电量、IP、升级这类非月付产品也不支持退订；限流套餐当天流量超过 100G 的，同样不在 7 天无理由范围内。违规用户一律不退。想先试水，用月付跑满一周比直接年付稳妥。

**续费没有新用户券。** 5 折券是首购福利，目前也没有公开的续费优惠码。年付 7 折属于活动折扣，续费时是否顺延要看续费页显示的价格，签长约前把这一点确认掉。

**支付方式比想象中多。** 支付宝、微信支付、云闪付、WeChatPAY HK、Alipay HK 都收，非大陆发行的 Visa / Master 也能付，但单次 200 元以上会被支付渠道收手续费。

**大带宽不等于低延迟。** 第三方测评里，香港五区这条线的下载峰值跑到 486Mbps，接近标称值，同时指出三网回程绕路明显，该款没有 DDoS 防御，SMTP 端口也大多被封。要发邮件、要稳定回国线路、要抗攻击的站点，别只看带宽数字。

**超流量是限速，不是停机。** 用完流量包后限速到 5Mbps，网站还能开，下载和大文件传输会明显变慢。跑下载站、视频中转的，把流量包成本算进月费里。

**备份自己留一份。** VPS 商给的控制台快照不能替代你自己的备份，数据库和上传文件定期导出一份到本地或对象存储，这条对任何一家 VPS 都成立。

## 机房和线路怎么选

选机房看两件事：访客在哪、晚高峰稳不稳。同一个套餐开在不同机房，体验能差出几倍。

**访客主要在中国大陆**：国内多线 BGP 节点（北京、上海、广州、宿迁、宁波）延迟最低，代价是备案和实名流程。想省掉备案，香港节点是常见折中，华南访问通常比美国西海岸快，但第三方测评提到香港五区这条大带宽线三网回程绕路，做对延迟敏感的站要先测。

**访客在海外、做外贸**：洛杉矶节点，公开资料标注走 AS9929 优化线路、无需备案，面向北美和欧洲客户都合适。

**只做下载、API 中转、AI 调用**：洛杉矶大带宽或香港五区大带宽，100M 到 1000Mbps 的出口是这类业务的刚需，延迟排第二位。

开通后第一件事是 ping 一下 IP。连不通就开工单让客服换，别自己折腾半天才发现是 IP 的问题。

## 从下单到网站上线的流程

1. 选档位和机房，确认计费周期（月付还是年付 7 折），付款。
2. 收开通邮件，里面有 IP、root 密码和控制面板地址，KVM 机型通常几分钟内开通。
3. SSH 登录，第一件事改密码、配 SSH 密钥，别用裸密码长期跑。
4. 装建站面板（宝塔一类），一行命令拉起 LNMP 环境，省去手配 Nginx、MySQL、PHP。
5. 面板里一键部署 WordPress，填域名和数据库信息。
6. 到域名服务商把 DNS 解析指向这台机器的 IP，站点上线。

第一次走完大概一两个小时，做过一遍之后半小时内能搞定。

## 常见问题

**1GB 内存能跑 WordPress 吗？** 能跑，前提是插件不多、不上 WooCommerce 这类重插件。想后台不卡、装几个常用插件，2GB 起步更稳。

**年付会不会第二年涨价？** 年付 7 折是活动折扣，续费时能不能延续，看续费页给出的金额。新用户 5 折券确定只作用于首购。

**IP 被墙了怎么办？** 开通后立刻 ping，不通就开工单换 IP。建站用途尽量选口碑稳定的机房，减少折腾。

**能不能退款？** 新购 7 天内可以在面板自助退，退到账户余额，每人 3 次机会。日付、流量包、IP、升级这类项目不退。

**没有 Linux 基础行不行？** 装个面板，日常操作基本在浏览器里点。SSH 只在第一次装面板时用，命令复制粘贴即可。

**需要备案吗？** 香港和洛杉矶节点在推广页上明确写的是无需备案。国内节点涉及备案与实名，下单页会有提示，别等站搭好才发现。
